# 妙笔AI 微信小程序 V1.4.0

这是可直接交给 WorkBuddy 或微信开发者工具继续配置、测试和上传的原生小程序项目。所有创作、润色、翻译与文本工具都请求你自己的 HTTPS 后端，再由服务端调用 DeepSeek；项目中没有 API Key，也没有 APPL 本地回退。

## 上线前只需替换两处

1. 在 `project.config.json` 中把 `touristappid` 改成你在微信公众平台申请的小程序 AppID。
2. 在 `miniprogram/config.js` 中把 `https://REPLACE_WITH_YOUR_HTTPS_DOMAIN` 改成已经部署 V1.4.0 国内版的 HTTPS 域名。

随后在微信公众平台“开发管理 → 开发设置 → 服务器域名”中，把同一个域名加入 `request 合法域名`。正式提交审核时不要关闭域名校验。

## WorkBuddy / 开发者工具操作

1. 导入此目录，项目类型选择“小程序”。
2. 填入真实 AppID。
3. 修改 `miniprogram/config.js` 的后端域名。
4. 编译并依次验收：首页访客额度、创作、工具箱、素材搜索、历史、注册登录。
5. 使用国内网站的站长账号进入 `/admin`，给测试用户邮箱赠送 1 天会员；回到小程序重新打开“我的账户”，确认变成会员且额度为 100。
6. 在不同手机上验证 10 次滚动 24 小时额度；失败的 DeepSeek 请求不能扣次数。
7. 完成隐私保护指引、类目和内容安全声明后上传体验版，再提交审核。

## 低成本边界

- 视频中提到的约 30 元是小程序认证环节的费用，不等于全部上线成本。
- 本项目复用国内 Cloudflare 后端，因此首版不单独购买服务器。
- 微信正式环境通常要求配置合规的 HTTPS 请求域名；若 `pages.dev` 不能加入合法域名，需要绑定自有域名并按微信后台要求完成备案或主体校验。
- 个人主体可选类目有限。妙笔AI优先按“工具/效率”方向准备，最终以微信公众平台当时允许的类目为准。
- 首版不在小程序内放个人收款码，避免支付和审核口径不清；人工收款暂留网站端。确认主体、类目和交易规则后再决定是否加入。

## 安全

- 不要把 DeepSeek API Key 写入 `config.js`、上传到 WorkBuddy 或提交到小程序代码。
- 聊天中公开过的旧 Key 必须先在 DeepSeek 控制台作废。
- 小程序登录令牌只保存在微信本机存储，并通过 HTTPS `Authorization: Bearer` 发给你的后端。
