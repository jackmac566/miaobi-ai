# 给 WorkBuddy 的执行任务

请导入本目录并完成妙笔AI微信小程序上线准备：

1. 保留现有原生小程序结构、五个底部栏目和 DeepSeek 服务端调用，不得把任何 API Key 写入前端。
2. 向项目所有者索取小程序 AppID 和已经部署成功的 V1.4.0 HTTPS 后端域名；只写入 AppID 与公开域名，不索取 DeepSeek 密钥。
3. 编译后逐页测试：首页、创作、工具箱、素材库、历史、账户登录/注册。
4. 用一个测试邮箱注册；让项目所有者在国内站 `/admin` 赠送 1 天会员；重新读取账户并截图证明 `isMember=true`、额度 100。
5. 验证访客和免费账号为滚动 24 小时 10 次，接口失败不会扣次数。
6. 检查所有 `wx.request` 只访问 `miniprogram/config.js` 中的同一个 HTTPS 后端。
7. 在微信公众平台配置 request 合法域名、隐私保护指引和适用类目；个人主体无法选择的类目不要绕过。
8. 首版不添加个人收款码或自动支付，不声称 30 元覆盖服务器、域名或 API 调用费用。
9. 生成体验版二维码和逐项验收记录，等待项目所有者确认后再提交审核。
